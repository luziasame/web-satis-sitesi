# web-satis-sitesi
BLM2537 Ağ Tabanlı Programlama - web satis sitesi projesi

#Kullanılan Teknolojiler
**HTML5:** Semantik etiket yapısı (`header`, `nav`, `main`, `section`, `footer`)
**CSS3:** Özel renk değişkenleri (`:root`), Flexbox düzeni, Kutu Modeli ve CSS animasyonları
**JavaScript (Vanilla JS):** İlerleyen aşamalarda sepet ve ürün yönetimi (CRUD) için entegre edilecektir.

#Klasör Yapısı
web-satis-sitesi/
      css/
          stil.css       # Proje renk paleti, düzen ve stil kuralları
      img/
           logo.png       # Ürün ve marka görselleri
      js/
            uygulama.js    # Dinamik işlevler ve sepet kodları
      index.html         # Ana sayfa (Karşılama, Vizyon, İletişim Footer)
      urunler.html       # Ürün kataloğu (Ceket & Pantolon)
      urun-detay.html    # Seçilen ürünün detay bilgileri
      sepet.html         # Sepet tablosu ve sipariş formu

#Proje herhangi bir sunucu veya veritabanı kurulumu gerektirmemektedir.
-Bu depoyu (repository) bilgisayarınıza indirin veya klonlayın
-git clone ( https://github.com/luziasame/web-satis-sitesi.git )
-Proje klasörünü Visual Studio Code ile açın.
-VS Code üzerindeki Live Server eklentisini kullanarak index.html dosyasını sağ tıklayıp "Open with Live Server" seçeneğiyle tarayıcıda başlatın.
-Alternatif olarak, index.html dosyasına çift tıklayarak doğrudan herhangi bir web tarayıcısında açabilirsiniz.
